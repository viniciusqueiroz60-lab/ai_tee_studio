1. Integração com Shopify Storefront API
Configure o Shopify JavaScript Buy SDK no projeto.

Crie um serviço de conexão usando as minhas credenciais do Shopify (AccessToken e Domain).

Altere o botão 'Comprar' para que, em vez de um checkout interno, ele utilize o método checkout.create do Shopify.
